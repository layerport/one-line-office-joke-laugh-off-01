## The joke

> My performance review called me a 'self-starter' — corporate for 'we stopped training you in 2019'.

## How it works

`main.py` (Python 3.13, standard library only) writes the joke above to
`/output/entry.txt` — one line, no trailing newline, fully deterministic:
every run produces byte-identical output.

## Run it

```bash
python3 main.py
```

The joke is written to `/output/entry.txt` (or to `$OUTPUT_PATH` if set).
